index.html (Single Page App)

الملف يضم الشاشات الثلاث في نظام واحد متصل:

1. تسجيل الدخول وتسجيل خادم جديد: حفظ بيانات الخادم واعتماد دخوله.
2. لوحة الخزائن والأقسام الثمانية: تسجيل الفواتير وحساب الأرصدة تلقائياً.
3. لوحة المشرف العام (الأدمن): إدارة الخدام وسجل الحركات الموحد.
يدعم التثبيت (PWA): يعمل مباشرة كتطبيق مستقل على هاتفك فور فتحه.
تم بدء التنزيل بنجاح! ستجده في مجلد التحميلات (Downloads).

كيف تستخدم الملف بعد تنزيله؟

  1. للتشغيل المباشر على الهاتف: افتح مدير الملفات واضغط على index.html ليفتح فوراً في المتصفح ويعمل كاملاً.
  2. للتحديث على GitHub / Vercel: ارفع الملف أو استبدل به الملف القديم في مستودع GitHub ليتم تحديث موقعك المباشر تلقائياً في ثوانٍ.
